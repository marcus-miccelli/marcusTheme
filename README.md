# Marcus Dark

A near-black VS Code theme designed for long sessions: minimal separation between surfaces, clear typography, and saturated syntax colours without a pastel cast.

The extension also includes **Marcus Seti**, a companion file-icon theme. It keeps the familiar Seti glyphs for TypeScript, JavaScript, JSON, and other file types, with their dark-theme colours lifted by 35% for clearer Explorer visibility.

After installing, choose:

- **Marcus Dark** from `Preferences: Color Theme`
- **Marcus Seti** from `Preferences: File Icon Theme`

## Recommended editor settings

The theme cannot change your font automatically. For the intended appearance, add this to your VS Code settings:

```json
{
  "editor.fontFamily": "'IBM Plex Mono', Consolas, monospace",
  "editor.fontSize": 14,
  "editor.fontLigatures": true
}
```
