# Changelog

## 1.0.0

- First stable release of Marcus Dark.
- Ships the near-black workbench, IBM Carbon syntax palette, and Marcus Seti file icons.

## 0.4.0

- Replaced the syntax palette with exact IBM Carbon scale values.
- Extended Carbon colours through editor diagnostics, brackets, diffs, cursors, and highlights.
- Replaced remaining Tokyo-derived syntax colours with Carbon neutral and categorical values.

## 0.3.2

- Changed functions and methods to red-pink.
- Changed general keywords to blue while keeping imports purple.
- Changed constants and decorators to orange.
- Separated numeric literals with a brighter saturated yellow.
- Kept type names purple.

## 0.3.1

- Increased syntax saturation using a Tokyo Night-inspired palette.
- Separated functions into blue and numbers into orange.
- Restored purple control keywords, including Python imports.
- Split cyan operators from neutral punctuation for clearer structure.

## 0.3.0

- Rebuilt syntax highlighting around restrained blue, green, and yellow families.
- Tuned code colours for clear but controlled contrast against the near-black editor.
- Retained red only for invalid and deleted content rather than ordinary syntax.

## 0.2.9

- Increased editor code and syntax-token brightness by 15%.
- Left UI text, terminal text, and Explorer file icons unchanged.

## 0.2.8

- Added the Marcus Seti file-icon theme with Explorer file glyphs brightened by 35%.
- Reverted the unrelated global workbench-icon brightening from 0.2.7.
- Kept Activity Bar hover and active icons pure white.

## 0.2.7

- Increased UI icon brightness by 35% without changing text or syntax colours.
- Lifted inactive Activity Bar icons while keeping hover and active icons pure white.

## 0.2.6

- Added explicit Modern UI Activity Bar colours.
- Restored pure-white icons for modern Activity Bar hover and active states.

## 0.2.5

- Reduced ordinary Explorer text brightness by approximately 15%.
- Restored pure-white active and hover emphasis for Activity Bar icons.

## 0.2.4

- Removed fallback focus and active-contrast outlines.
- Cleared terminal focus, hover, match, overview, and active-tab borders.
- Preserved the structural editor-to-panel separator.

## 0.2.3

- Replaced outline-based hover cues with filled region highlights.
- Added distinct hover, selected, focused, and active surface levels.
- Unified hierarchy across lists, editor tabs, terminal tabs, and toolbar controls.

## 0.2.2

- Replaced active editor-tab accent lines with a single solid region highlight.
- Removed foreground hover changes from editor tabs.
- Kept toolbar and terminal hover backgrounds transparent.
- Preserved Explorer row hover within VS Code's shared list-colour limitation.

## 0.2.1

- Moved Explorer into the darkest surface layer.
- Lifted the editor and terminal onto the former Explorer surface colour.

## 0.2.0

- Rebuilt the editor text palette around softer graphite and mineral tones.
- Reserved near-white for selections and control emphasis.
- Removed stacked hover backgrounds from selected list, terminal, and tab states.

## 0.1.0

- Initial preview release.
- Near-black workbench and editor surfaces.
- IBM Plex Mono recommendation.
- High-readability foreground with restrained saturated syntax colours.
